GETTING STARTED

A few seconds
Then a little space.

No installer wizard or administrator prompt. Start from the official release.

Full installation guide ↗
  1. Download the application.

    Get HideIcons.exe from the official GitHub release.

  2. Start it normally.

    Launch the executable as your regular Windows user. Its icon appears in the notification area.

  3. Make room.

    Left-click to show or hide desktop icons. Right-click for the settings menu.

  4. Choose your shortcut.

    Use Set Hotkey to assign a global shortcut. Startup and custom-icon controls are in the same menu.

To remove: disable Run at Startup, exit the app, then delete its files. Preferences are stored under your Windows user account.

A LITTLE MORE CONTEXT

Good to know.

Does it delete my icons?+

No. It toggles desktop-icon visibility through the desktop’s own command.

Can I undo my shortcut?+

Choose Remove Hotkey from the tray menu. You can assign a different shortcut later.

How do I stop startup?+

Right-click the tray icon and turn off Run at Startup before removing the application.
